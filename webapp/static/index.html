Salesforce Release Impact Check

Compare your org with the next Salesforce release and generate the impact documentation.

1

Log in to Salesforce

You are sent to the Salesforce login page (MFA and SSO work as usual), then back here. The tool only reads metadata and configuration. Nothing is changed in the org. Tokens stay in this app's memory and are discarded when it stops.

2

Connect Claude

  1. On your computer, open a terminal where Claude Code is installed and run claude setup-token.
  2. Sign in with your Claude account in the browser that opens. This can be your company's Team or Enterprise account (for example the partner account), Pro or Max.
  3. Copy the token it prints (it starts with sk-ant-oat) and paste it here.

The analysis runs on Claude Code, the official Claude client, and counts against your Claude plan's usage limits. There is no API bill. The token is kept in memory only. Your Claude admin may need to allow Claude Code for your seat.
